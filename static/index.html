作品解析

DOUYIN × TIKTOK

粘贴链接，一键解析

支持分享文案、短链接、作品链接与作品 ID。解析后可直接预览并下载视频、图集、音乐与封面。

当前平台：抖音
高级选项 Cookie / 代理

最近解析

账号作品

采集账号发布页或喜欢页中的作品，可设置日期范围与分页参数。

抖音
抖音主页链接可直接粘贴，会自动提取 sec_uid；也可填写短链接。TikTok 需填写 secUid。
高级选项 Cookie / 代理 / 原始数据
返回原始响应开启后直接展示 API 的原始数据结构
喜欢页需要登录 Cookie 才能获取完整数据；多页采集可能需要数十秒。

合集作品

通过合集 ID 或合集内任意作品 ID 获取整个合集 / 合辑的作品列表。

抖音
与下方“作品 ID”二选一，优先级更高。
高级选项 Cookie / 代理 / 原始数据
返回原始响应开启后直接展示 API 的原始数据结构

直播解析

获取直播间信息与拉流地址，可复制到播放器中使用。

抖音
当前服务端版本的 TikTok 直播接口可能存在字段缺失问题；若返回 500，请以服务端日志为准。
可从直播链接 https://live.douyin.com/<web_rid> 中获取。
高级选项 Cookie / 代理 / 原始数据
返回原始响应开启后直接展示 API 的原始数据结构

评论采集

采集作品下的一级评论，可选择同时收集回复。

仅支持抖音
评论接口仅支持抖音；部分评论需要登录 Cookie 才能获取。
同时采集回复开启后会额外请求评论回复数据，耗时更长
高级选项 Cookie / 代理 / 原始数据
返回原始响应开启后直接展示 API 的原始数据结构

搜索发现

按关键词搜索抖音综合内容、视频、用户或直播。

仅支持抖音
综合结果会混合返回视频、用户、直播等数据
高级选项 Cookie / 代理 / 原始数据
返回原始响应开启后直接展示 API 的原始数据结构

全局配置

读取并更新服务端的 settings.json。保存后立即生效，无需重启 API 服务。

Cookie、浏览器信息等字段包含敏感数据，只会在本机浏览器与本地 API 之间传输。修改前建议先导出一份配置备份。
